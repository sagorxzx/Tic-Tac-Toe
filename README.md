# ✨ Crystal Tic-Tac-Toe

A beautifully designed, glass-morphic Tic-Tac-Toe game with smooth animations and AI opponent.

## 🎮 Features

- **Two Game Modes:**
  - 🎮 **Single Player** - Play against an intelligent AI
  - 👥 **Two Player** - Play with a friend on the same device

- **Visual Features:**
  - Glassmorphic design with blur effects
  - Smooth SVG animations for X and O marks
  - Responsive layout for all screen sizes
  - Beautiful gradient backgrounds
  - Popup victory/draw notifications

- **Game Features:**
  - Score tracking (X wins, O wins, Draws)
  - AI with smart decision making (win/block/center/corner strategy)
  - Turn indicator with clear messaging
  - Reset button to start fresh
